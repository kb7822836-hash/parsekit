JSON Diff

Compare two JSON documents and see exactly what was added, removed or changed. Runs entirely in your browser, nothing you paste is uploaded anywhere.

What is a JSON diff?

    
A JSON diff compares two JSON documents and lists the differences between them. It is useful for checking what changed between two API responses, two versions of a config file, or a test result and its expected value.

    
How to use it

    
Paste the original JSON on the left and the changed JSON on the right, then press Compare. Each difference is shown with its path, for example $.user.age, so you can find it quickly.

    
How are arrays compared?

    
Arrays are compared position by position. If an item is inserted at the start of an array, the items after it will show as changed. Object keys are compared by name, so the order of keys does not matter.

    
Is my data safe?

    
Yes. The comparison happens in your browser with JavaScript. Nothing is sent to a server.
