What this tool does

    
CSV is flat rows and columns, while JSON is structured data that apps and APIs can read. This tool takes your CSV, uses the first row as field names, and turns every following row into a JSON object. The result is a JSON array of objects, ready to use in code, an API request or a database import.


    
Example

    
CSV input:

    
name,city,age
Ali,Jhelum,24
Sara,"Lahore, Punjab",30

    
JSON output:

    
[
  {
    "name": "Ali",
    "city": "Jhelum",
    "age": 24
  },
  {
    "name": "Sara",
    "city": "Lahore, Punjab",
    "age": 30
  }
]

    
The comma inside "Lahore, Punjab" stays part of the value because that field is wrapped in double quotes.


    
Options

    
Delimiter: Auto-detect reads the first line and picks comma, semicolon, tab or pipe. Choose one yourself if the guess is wrong.

    
First row is header: when ticked, the first row becomes the keys of every object. When cleared, you get an array of arrays instead.

    
Convert numbers and true/false: when ticked, values such as 24 and true become real JSON numbers and booleans. Values with leading zeros, like 007, stay as text so nothing is lost. Clear the box to keep every value as a string.


    
Common uses for CSV to JSON

    
Turn a spreadsheet into API data. Export a sheet from Excel or Google Sheets as CSV, convert it here, and use the JSON in a request body or a mock API.

    
Load data into an app or database. Many importers and NoSQL databases expect JSON, so a CSV export can be converted first and then imported.

    
Create test data and config files. Keep rows in a spreadsheet where they are easy to edit, then convert them to JSON when you need fixtures.

    
The conversion runs in your browser, so private data is never uploaded, and there are no usage limits.


    
Frequently asked questions

    
How do I convert CSV to JSON?

    
Paste your CSV into the input panel, or open a .csv file with the Open file button, then press Convert to JSON. Each row becomes an object and the first row supplies the keys.

    
Does it handle commas and line breaks inside quoted values?

    
Yes. A field wrapped in double quotes can contain commas, line breaks and doubled quotes, and it is read as a single value.

    
Can it read semicolon or tab separated files?

    
Yes. Auto-detect checks the first line for a comma, semicolon, tab or pipe. You can also pick the delimiter yourself.

    
What does Convert numbers and true/false do?

    
It turns values like 24 or 3.5 into JSON numbers and the words true and false into booleans. Clear the option to keep every value as text.

    
Is my CSV uploaded to a server?

    
No. The conversion runs in your browser with JavaScript, so what you paste stays on your device.

    
Can I convert JSON back to CSV?

    
Yes, use the JSON to CSV converter.
