about

Small tools, done properly

Parsekit (parsekit.net) is a collection of free, single-purpose JSON and data tools that run entirely in your browser. It is not affiliated with other software projects that share the name.

Most JSON tools online are bundled into bloated, ad-heavy sites that bury a simple utility behind popups and multi-step wizards. Parsekit takes the opposite approach: every tool is a single page, does one job, and gives you an answer in seconds.

What's available today

Nine free tools, each on its own page: format and validate JSON, convert JSON to CSV, convert JSON to YAML, merge JSON files, compare two JSON files, split a large JSON file, escape and unescape JSON strings, encode and decode Base64, and encode and decode URLs. More tools are planned as this grows.

How it works

Every tool runs entirely in your browser using JavaScript already loaded on the page. Nothing you paste in is sent to a server or stored anywhere, and the tools work offline once the page has loaded. The site does use Google Analytics for basic page-view and button-click counts, which never include what you paste. See the Privacy Policy for details.
