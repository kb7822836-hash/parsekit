about

Small tools, done properly

Parsekit is a growing collection of single-purpose JSON tools, built so each one does exactly one job well.

Most JSON tools online are bundled into bloated, ad-heavy sites that bury a simple utility behind popups and multi-step wizards. Parsekit takes the opposite approach: every tool is a single page, does one job, and gives you an answer in seconds.

What's available today

Three tools cover the most common JSON tasks: formatting and validating JSON, converting JSON to CSV for spreadsheets, and merging two JSON files into one. More tools — covering other data formats — are planned as this grows.

How it works

Every tool runs entirely in your browser using JavaScript already loaded on the page. Nothing you paste in is sent to a server or stored anywhere. That also means these tools work offline once the page has loaded.
