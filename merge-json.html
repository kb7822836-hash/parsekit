Merge JSON Files Online

Combine two JSON files into one. Open each file in any text editor, copy its contents, and paste them into the two panels below. Parsekit does a deep merge for objects (matching keys are combined, and conflicts are won by the second panel) or joins two arrays end to end. Everything runs in your browser, so nothing is uploaded.

How to merge two JSON files

    
Open both files in a text editor, copy the first file's contents into panel A and the second file's contents into panel B, then press Merge. The combined JSON appears in the result box, and you can copy it or download it as a .json file.


    
How the merge works

    
If both inputs are objects, Parsekit merges them key by key. When a key holds another object on both sides, it merges those nested objects too, going as deep as needed. When a key's value is a plain value or an array on either side, the value from JSON B replaces the one from JSON A.


    
Example: merging two objects

    
JSON A:

    
{"user":{"name":"Ali","age":24}}

    
JSON B:

    
{"user":{"age":25,"city":"Jhelum"}}

    
Merged result:

    
{"user":{"name":"Ali","age":25,"city":"Jhelum"}}

    
The nested user objects were combined. The age conflict was won by JSON B, and the name and city were both kept.


    
Combining JSON arrays

    
If both inputs are arrays instead of objects, they are joined end to end into one longer array. Nothing is deduplicated, so repeated items are kept.

    
For example, combining [1,2] and [2,3] gives [1,2,2,3].


    
Frequently asked questions

    
What happens when both files have the same key?

    
If both sides hold an object for that key, the two objects are merged recursively. Otherwise, the value from JSON B wins and replaces the value from JSON A.

    
Can I merge more than two files?

    
This tool merges two inputs at a time. To combine three or more, merge the first two, then paste that result back into panel A along with the third file in panel B, and repeat.

    
What if one file is an array and the other is an object?

    
Both inputs need to be the same shape: two objects, or two arrays. If they don't match, the tool shows an error instead of guessing how to combine them.

    
Are my JSON files uploaded to a server?

    
No. The merge runs entirely in your browser with JavaScript. Nothing you paste leaves your device, so it is safe to use with private or sensitive data.

    
Does merging remove duplicate items from arrays?

    
No. Arrays are joined as they are, and repeated items are kept. If you need unique values only, remove the duplicates from the result afterwards.

    
Is this JSON merge tool free?

    
Yes. It is free, needs no signup, and has no usage limits.

    
How do I check what changed after merging?

    
Use the JSON Diff tool to compare the original file with the merged result and see exactly which keys were added or changed.
