\# Parsekit



Free online JSON tools that run entirely in your browser. Nothing you paste is uploaded to a server.



Live site: https://parsekit.net



\## Tools



\- \[JSON Formatter \& Validator](https://parsekit.net/json-formatter.html)

\- \[JSON to CSV Converter](https://parsekit.net/json-to-csv.html)

\- \[CSV to JSON Converter](https://parsekit.net/csv-to-json.html)

\- \[Merge \& Combine JSON Files](https://parsekit.net/merge-json.html)

\- \[JSON Splitter](https://parsekit.net/json-splitter.html)

\- \[JSON Compare and Diff](https://parsekit.net/json-diff.html)

\- \[JSON Escape / Unescape](https://parsekit.net/json-escape-unescape.html)

\- \[JSON Repair](https://parsekit.net/json-repair.html)

\- \[JSON to YAML](https://parsekit.net/json-to-yaml.html)

\- \[Base64 Encode / Decode](https://parsekit.net/base64-encode-decode.html)

\- \[URL Encode / Decode](https://parsekit.net/url-encode-decode.html)



Guide: \[JSON parse errors explained](https://parsekit.net/json-parse-errors.html)



\## How it works



Every tool is plain HTML, CSS and JavaScript. All processing happens in your browser, so your data stays on your device. The site uses Google Analytics for anonymous usage statistics; see the \[privacy policy](https://parsekit.net/privacy.html).



\## Run locally



```bash

git clone https://github.com/kb7822836-hash/parsekit.git

cd parsekit

\# open index.html in a browser, or serve the folder:

npx serve .

```
