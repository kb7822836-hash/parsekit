tool 08 / split

Split JSON File Online

Break a large JSON file into smaller parts. Open the file in a text editor, copy its contents, paste them below, and choose how many items each part should hold. Arrays are split by items, and objects are split by keys. Everything runs in your browser, so nothing is uploaded.

JSON input (array or object)

How to split a JSON file

Copy the contents of your JSON file into the input box, set how many items you want in each part, and press Split. Each part appears below with its own Copy and Download buttons, so you can save the pieces as separate .json files.

How the split works

If the input is an array, it is cut into groups of the size you choose, in the original order. If the input is an object, its top-level keys are divided into groups, and each part is a smaller object holding those keys. The last part may hold fewer items than the others.

Example: splitting an array

Input:

[1,2,3,4,5]

With 2 items per part, you get three parts:

[1,2]   [3,4]   [5]

Frequently asked questions

Is my JSON uploaded to a server?

No. The split runs entirely in your browser with JavaScript. Nothing you paste leaves your device, so it is safe to use with private data.

Can I split a JSON object, not just an array?

Yes. For an object, the top-level keys are divided into groups and each part is a smaller object with those keys.

Does splitting change my data?

No. Items keep their original order and values. Each part is formatted with two-space indentation, which only changes whitespace.

How big a file can I split?

It depends on your browser and device, since everything is processed locally. Files of a few megabytes work fine. Very large files may be slow to paste into the box.

Can I download all the parts at once?

Each part has its own Download button. Browsers restrict many simultaneous downloads, so the parts are saved one at a time.

How do I put the parts back together?

Use the Merge JSON tool. For arrays, merging two parts joins them end to end again.
